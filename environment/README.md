# Environment

This directory will record the software/runtime environment used by the frozen analyses. Exact versions must be taken from preserved project artifacts or executed notebooks; they must not be reconstructed from memory.

Expected fields include Python, PyTorch, torchvision, timm, CUDA, scikit-learn, operating system, and GPU information. The manuscript records NVIDIA L4 for E2-A and external evaluations and NVIDIA T4 for the preliminary E1 benchmark.
