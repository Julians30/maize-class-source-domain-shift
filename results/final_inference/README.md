# Final internal inference layer

This directory contains the compact, manuscript-facing internal inference assets generated from the 18 frozen E2-A runs (6 architectures × 3 seeds) on the fixed 1,719-image internal test set.

The files in this directory are intended to support final reporting of point estimates, uncertainty, paired architecture comparisons, ensemble analysis, selective-risk summaries, calibration/reliability summaries, and class-level consensus difficulty.

These assets are derived analytical outputs. They do not contain original image pixels and should not be interpreted as granting redistribution rights to any source imagery.
